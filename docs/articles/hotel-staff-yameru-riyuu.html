ホテルスタッフはなぜ辞める人が多いのか?離職理由と実態を公的統計から整理

📋 辞める理由・課題まとめ

  • 感情労働としての負荷
  • キャリアパスが見えにくい
  • 教育体制と人間関係

「お客様に喜んでもらえるのは好きなのに、このまま続けられる気がしない」——ホテルで働く人から、こうした声が聞かれることは少なくありません。

一方で、ホテルの仕事を心から楽しみ、長く続けている人も大勢います。この記事の目的は「ホテルは辞めたほうがいい」と結論づけることではなく、なぜ離職の話題が出やすい職種なのかを、公的統計と業界調査から冷静に整理することです。そのうえで、今の職場で工夫できることと、外に目を向ける選択肢の両方を並べます。

なお本記事では、読者の判断材料として転職支援サービスのジャンルに触れる箇所があり、一部にアフィリエイトリンクを含む場合があります(特定の1社を推奨するものではありません)。

統計で見る:ホテル・宿泊業の離職率はどのくらいか

まず、体感ではなく数字から確認します。調査年によって数値が動くため、年次を明記しながら見ていきます。

厚生労働省「令和6年雇用動向調査」では、産業計の年間離職率は14.2%でした(前年の令和5年調査は15.4%)。ホテル・旅館が含まれる「宿泊業,飲食サービス業」は就業形態別に公表されており、一般労働者18.1%、パートタイム労働者29.9%と、いずれも産業全体の水準を上回っています。

参考までに、前年の令和5年調査では同産業の離職率は26.6%(産業計15.4%)で、主要産業の中でもっとも高い水準でした。「宿泊・飲食は離職率が最も高い」という言われ方の根拠は、主にこのあたりの数字です。

ただし、この数字の読み方には注意が必要です。

  • この区分には飲食サービス業が合算されており、ホテル単体の数値ではありません
  • パートタイム労働者の比率が高い産業であり、短期雇用の入れ替わりが全体の数値を押し上げます(上の内訳のとおり、パートタイムのほうが離職率は高く出ます)
  • 同時に入職率も産業中で高い水準にあります。つまり「人が出ていくだけの業界」ではなく、出入りが激しい業界という表現のほうが実態に近いといえます

もう一つよく参照されるのが、厚生労働省「新規学卒就職者の離職状況」です。大学新卒者全体の就職後3年以内離職率は33.8%(令和4年3月卒業者、2025年公表)でしたが、産業別に見ると「宿泊業,飲食サービス業」は例年5割前後で最上位圏に位置しています。新卒で入った人の半数近くが3年以内に次の道を選んでいる、という状況が続いています。

さらに人手の状況として、帝国データバンクの人手不足に関する調査(2025年1月調査)では、ホテル・旅館の60.2%が正社員不足と回答しています。辞める人が多いことと残った人の負荷が増えることが連動しやすい構造がうかがえます。

出典:厚生労働省「令和6年雇用動向調査結果の概況」/同「新規学卒就職者の離職状況」(2025年公表)/帝国データバンク「人手不足に対する企業の動向調査(2025年1月)」

前提:離職は「ネガティブな理由」だけではない

離職理由を語るとき、つらさの話に偏りがちですが、実際には前向きな転職も相当数含まれます。

観光庁が2025年3月に公表した令和6年度「宿泊業の人材確保・育成の状況に関する実態調査事業」では、宿泊業から離職した人への調査で、体力面・精神面・業務量に関する回答も多い一方、もっとも割合が大きかったのは「自分のしたい業務ができなかったから」という趣旨の回答でした。

「きつかったから逃げた」ではなく、「やりたいことと、任された仕事がずれていた」。これは能力や根性の問題ではなく、マッチングの問題です。この視点は、自分の状況を振り返るときにも役立ちます。

ホテルスタッフの離職理由:よく挙がる7つの要因

ここからは、公的統計・業界調査で繰り返し登場する要因を7つに整理します。厚生労働省の雇用動向調査で自己都合離職者が挙げる理由としては、産業全体でも「労働時間・休日等の労働条件」「賃金」「職場の人間関係」「仕事内容への不満」が上位に並ぶ傾向があり、以下はそれをホテル特有の事情に落とし込んだものです。

なお、統計で確認できる話と、現場から挙がる声として語られる話は区別して示します。後者には「※統計的な裏付けはなく、現場の声として紹介されるもの」と注記します。

1. 勤務時間の不規則さと拘束時間の長さ

ホテルは24時間365日稼働する施設です。早番・遅番・夜勤(ナイト)のシフト制が基本で、生活リズムが一定になりにくい働き方が構造的に生じます。

一部の施設で見られる「中抜けシフト」——朝食対応の後に数時間空け、夕食対応でまた勤務に入る形——では、実労働時間は規定内でも拘束時間が長くなりやすいという指摘があります。導入の有無や運用は施設・部門によって大きく異なるため、「旅館やレストランなら必ずそう」というものではありません。

休暇については、厚生労働省「就労条件総合調査」において、宿泊業,飲食サービス業の年次有給休暇取得率は産業別で下位に位置する年が続いています。「休みは取れるが、まとまって取りにくい」という声の背景には、この数字があります。

一方、労働時間の統計を見るときは注意が必要です。毎月勤労統計調査では、同産業の総実労働時間はパートタイム比率の高さから産業平均より短く出ます。長時間労働の議論をする際は、一般労働者(フルタイム)に限った数値で比べる必要があります。

2. 賃金水準が産業全体の中で低めに出やすい

厚生労働省「賃金構造基本統計調査」において、宿泊業,飲食サービス業の平均賃金は産業別で最も低い部類に位置し続けています。令和6年調査では月26万9,500円(所定内給与額)でした。賃金統計は毎年更新されるため、最新値は厚労省の公表ページで確認してください。

背景としては、施設維持費や人件費比率の高さといったコスト構造、労働集約型サービスという業態特性の影響も指摘されています(個々の企業の姿勢だけで説明できるものではありません)。責任や語学対応スキルが増えても給与の伸びを実感しにくい——この「負荷と報酬のギャップ」は、離職を考えるきっかけになりやすい要因です。

3. 繁閑差と人手不足による業務負荷

インバウンドを含む宿泊需要は回復・拡大しましたが、前述のとおり帝国データバンクの2025年1月調査ではホテル・旅館の6割が正社員不足と回答しており、需要の回復に人員補充が追いついていない状況がデータからうかがえます。

その結果として、繁忙期にはフロントがハウスキーピングを手伝う、宴会に他部門から応援に入るといった兼務が生じやすくなります。「一人あたりの守備範囲が広がったまま固定される」という負担感は、現場から挙がる声としてよく語られます(※これ自体は統計的に測定された数値ではありません)。

4. 感情労働としての負荷

ホテルの仕事は、常に一定水準以上の表情と言葉遣いを保つことが求められます。こうした感情労働は、身体的な疲労とは別種の消耗をもたらすものとして、労働研究の分野でも扱われてきた概念です。

近年は口コミサイトの評価が事業に直結するため、クレーム対応の重みも増しているといわれます。制度面では、2020年施行の改正労働施策総合推進法で義務化されたのはパワーハラスメント防止措置であり、カスタマーハラスメント(顧客等からの著しい迷惑行為)への対応は、当時は指針上の「望ましい取組」という位置づけでした。その後、2025年6月公布の改正法により、カスタマーハラスメント対策(相談体制の整備等)が事業主の義務となり、2026年10月に施行されます。対応の進み具合には事業者間で差があるのが現状です。

5. キャリアパスが見えにくい

フロント→アシスタントマネージャー→マネージャーというルートは、ポストの数が限られます。また、部門特化で専門性を深めた場合、それが他業界でどう評価されるのかが分かりにくい、という声もあります。

この点について統計で言えるのは、前述の観光庁調査で離職理由の最多が「自分のしたい業務ができなかったから」だったという事実です。待遇の問題と並んで、仕事内容とキャリアの納得感が離職の大きな分岐点になっていることが読み取れます。

6. 教育体制と人間関係

離職が多い職場ほど、OJT(現場で教えながら育てる方式)の担い手が不足し、十分な教育の前に実務に出ざるを得なくなる——という循環は、業界メディアや現場のインタビューでしばしば語られます(※統計的に検証された因果関係ではなく、現場の声として紹介されるものです)。

雇用動向調査では自己都合離職の理由として「職場の人間関係が好ましくなかった」が産業を問わず上位に入ります。少なくとも、これを個人の資質の問題だけに帰するのではなく、人員配置や教育リソースの問題としても捉える視点は持っておいてよいでしょう。

7. ライフステージとの両立

土日祝・年末年始・大型連休が繁忙期という性質上、家族や友人と休みが合いにくい働き方になります。また、チェーン系では異動・転勤を伴う場合もあり、結婚・出産・育児・介護といったライフイベントのタイミングで働き方の再設計を迫られるケースがあります。

職種によって「しんどさの種類」は違う

ひとくちにホテルスタッフといっても、負荷のかかり方は部門で異なります。自分の不満がどこから来ているのかを切り分けると、打ち手が見えやすくなります。以下は、求人情報や業界の職務解説で一般に説明される傾向をまとめたもので、施設によって実態は異なります。

部門負荷が集中しやすいとされるポイント
フロント・ゲストリレーション夜勤を含むシフト、クレームの一次受け、多言語対応
ベル・ドアマン立ち仕事・荷物対応などの身体負荷、天候の影響
ハウスキーピング時間あたり客室数の目標、身体負荷、繁忙期の集中
レストラン・調理長時間の立ち仕事、繁閑差、施設によっては中抜けシフト
宴会・婚礼土日祝への偏り、目標数値の責任、当日の緊張度
予約・レベニュー・管理部門数値責任、繁忙期の対応量、専門知識の更新

知っておきたい業界用語

  • ADR:平均客室単価。1室あたりの平均販売価格
  • OCC:客室稼働率
  • RevPAR:販売可能な客室1室あたりの収益。ADR×OCCで算出
  • レベニューマネジメント:需要予測に基づく価格・在庫の最適化業務
  • 中抜けシフト:1日の勤務を朝と夕方に分け、間に長い休憩を挟む勤務形態
  • ナイト(夜勤):深夜帯のフロント業務。夜間監査(ナイトオーディット)を伴うことが多い
  • OJT:実務を通じた現場教育

これらは転職活動時の求人票や面接でも頻出します。用語の意味を押さえておくと、求人票から労働環境を読み解く精度が上がります。

一方で、環境は変わりつつある

離職理由ばかり並べると悲観的に見えますが、ここ数年で動いている部分もあります。

  • 客室単価の上昇:東京商工リサーチの集計によると、主要ホテル運営企業の平均客室単価(ADR)は2025年7〜9月期で1万6,975円と上昇傾向にあります。待遇改善の原資が生まれやすい局面といえます
  • 処遇改善への関心:観光庁の実態調査でも、人材の確保・定着に向けた取組として賃金・処遇の改善を挙げる事業者が多く見られます。民間の業界向け調査でも賃上げ予定に関する数値が公表されていますが、調査主体やサンプル数によって結果が変わる点には留意が必要です
  • 省人化・DX:セルフチェックイン、PMS(宿泊管理システム)連携、清掃管理アプリなどの導入で、定型業務の負荷を下げる取り組みが広がっています
  • 働き方の選択肢:住宅補助・寮制度、シフトの希望制、短時間正社員など、制度面の整備を進める事業者も出てきています

つまり、業界全体が一様に厳しいわけではなく、事業者間の差が広がっているというのが現在の実態に近い見方です。「業界を出る」以外に「同じ業界の別の環境を選ぶ」という選択肢も現実味を持ちやすいタイミングです。

辞める前に整理しておきたい5つのこと

もし今、辞めることが頭をよぎっているなら、動く前にこの5点を書き出してみることをおすすめします。

  • 不満の発生源はどこか:業界構造そのものか、部門特有か、特定の人間関係か、今の繁忙期だけの話か
  • 数字で把握する:直近3か月の実労働時間、休日数、有給取得日数、手取り額。感覚ではなく数字にすると比較ができます
  • 社内で動かせる余地はあるか:部門異動、系列施設への異動、シフト形態の相談。制度として存在するのに使われていないケースは珍しくありません
  • 自分の市場価値の棚卸し:多言語対応、PMS操作、売上管理、クレーム対応、シフト作成、スタッフ育成。ホテル経験は、接客・ブライダル・商業施設運営・人材・不動産・航空・BtoBの顧客対応職などに接続しうるスキルの集合です
  • 健康状態:睡眠・食事・気分の落ち込みが続く場合は、キャリアの判断より先に休養と専門家への相談が優先されます

「続ける」と「変える」を比べるための選択肢

判断材料を増やす、という意味では、在職中に情報だけ集めておく方法があります。実際に応募するかどうかは、後から決めれば十分です。

代表的な選択肢のジャンルを挙げます(特定の1社を推奨するものではありません)。

  • ホテル・観光・ブライダル特化型の転職エージェント:業界内の別施設・別業態への移動を考える場合に、施設ごとの労働環境やシフト実態の情報を持っていることがあります
  • 総合型の大手転職エージェント:業界の外に出る可能性も含めて、幅広く求人を見たい場合に向きます
  • 接客経験を評価する異業種向けサービス:販売・カスタマーサクセス・人材・不動産など、対人スキルを軸に職種転換を検討する場合の選択肢
  • 地域特化型のサービス:Uターン・Iターンや、通勤圏を変えたい場合
  • 求人検索型の転職サイト:誰にも相談せず、まず相場や条件だけ静かに眺めたいとき

選ぶ際は、扱う求人の領域(業界内か業界外か)、担当者の業界理解度、在職中でも面談しやすい時間帯に対応しているかの3点を比べると、自分に合うものが絞りやすくなります。複数を並行して使い、合わないと感じたら止める、という進め方でも問題ありません。

読み終えたあとの、次の一歩

いきなり退職届を書く必要はありません。負担の小さい順に、こんな段階があります。

  • 直近3か月の労働時間・休日・手取りを紙に書き出す
  • 同じ職種・同じ地域の求人を2〜3件だけ見て、条件の相場を知る
  • 社内の異動・制度について、使える選択肢があるか確認する
  • 必要なら、業界特化型と総合型のエージェントを1社ずつ比べてみる

「辞める/辞めない」を今日決めなくても、選択肢を知っている状態は、それだけで日々の見え方を変えてくれることがあります。

この記事についての注記

本記事で紹介した離職理由は、公的統計や業界調査で共通して挙がる傾向をまとめたものであり、ホテルで働くすべての人に当てはまるものではありません。同じ業界・同じ職種でも、施設の規模、運営方針、部門、上長、地域によって働き方は大きく異なり、感じ方にも個人差があります。ホテルの仕事にやりがいを持ち、長く活躍している方が数多くいることも、同じ事実です。
