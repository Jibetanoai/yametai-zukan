病院看護師はなぜ辞める人が多いのか?離職率11.0%の実態と主な離職理由を統計から整理

「もう限界かもしれない」と感じる日もあれば、「やっぱりこの仕事が好きだ」と思える日もある——同じ病棟で同じ夜勤をこなしていても、感じ方は人によって、また時期によって大きく違います。

「看護師は辞める人が多い」。よく聞く話ですが、実際の統計を確認すると、イメージとは少し違う姿が見えてきます。この記事では、日本看護協会や厚生労働省の調査データをもとに、病院看護師の離職率の実態と、調査で挙げられている離職理由を整理します。そのうえで、「今の職場で続ける」「環境を変える」を考えるための視点をまとめました。

※この記事では、転職支援サービス等のジャンルを紹介する箇所があり、そこにアフィリエイトリンクを含む場合があります。サービスの説明は一般的なジャンルの紹介にとどめ、特定の1社を断定的に推すことはしません。

先に結論:「離職率が高い」より「人の出入りが多い」職種

データを踏まえた要点を先にまとめます。

  • 病院で働く正規雇用看護職員の離職率は、2024年度で 11.0%(日本看護協会「2025年 病院看護実態調査」2026年3月公表)。前年度の11.3%からわずかに低下しました。
  • この数字と、他産業の離職率を単純に比較することはできません。日本看護協会の調査は「病院単位・正規雇用の看護職員・年度集計」、厚生労働省「雇用動向調査」は「事業所単位・パートを含む常用労働者・暦年集計」で、母集団も定義も異なるためです。
  • 参考として、厚生労働省「令和6年雇用動向調査」では、全産業の離職率は14.2%(前年15.4%)、「医療,福祉」分野は16.9%で、入職率も18.3%と高い水準です。つまり業界全体としては入職も離職も活発な分野であり、少なくとも「看護職だけが突出して職場を離れている」と読める数字ではない、という整理になります。
  • 「離職率」はその病院を離れた人の割合であり、看護職そのものを辞めた人の割合ではありません。資格を持ったまま別の病院・施設へ移る人が相当数含まれます。
  • 一方で、新人期のメンタル面の負担や夜勤の長時間化など、平均値には表れにくい課題が各調査で繰り返し指摘されています。

データで見る:病院看護師の離職率

全体の数字(2024年度実績)

日本看護協会「2025年 病院看護実態調査」(2026年3月公表・2024年度実績)では、次のようになっています。

区分離職率(2024年度)前年度(2023年度)
正規雇用看護職員11.0%11.3%
新卒採用者8.4%8.8%
既卒採用者16.1%16.1%

注目したいのは、新卒採用者の離職率が8.4%と全体より低い点です。「新人がどんどん辞めていく」というイメージが語られがちですが、少なくとも全国平均で見れば、1年目で職場を離れる人は10人に1人弱という水準にとどまります。

一方で高いのが既卒採用者(中途入職者)の16.1%です。転職して入職した人が比較的短期で再び動くケースが一定数あることがうかがえます。転職を検討している人にとっては、後述するとおり重要な示唆になります。

職場の条件によって数字はかなり違う

平均値だけを見ると実感とズレます。日本看護協会「2024年 病院看護実態調査」(2025年3月公表・2023年度実績)では、条件による差が報告されています。以下はいずれも2023年度実績の数値です。

  • 設置主体別:医療法人が14.4%と、他の設置主体より高め。
  • 病床規模別:99床以下・100〜199床といった中小規模の病院で相対的に高い傾向(12.6%)。
  • 都道府県別:東京都14.2%、大阪府13.7%、神奈川県13.6%が上位。一方、岩手県・山形県は6.8%と、地域による開きが2倍前後あります。

数字の読み方について

離職率の高低は、その職場の良し悪しを直接示すものではありません。近隣に医療機関が多いほど転職の選択肢が増える、規模が大きいほど院内異動で対応できる、中途採用の比率が高い、といった構造的な要因が影響します。また上記は2023年度実績であり、年度によって順位や水準は変動します。

「自分の周りではよく人が辞める」という感覚は、全国平均ではなく、勤務先の規模・地域・設置主体といった条件を反映している可能性があります。

業界全体としては「入る人も多いが、出る人も多い」

先に触れたとおり、厚生労働省「令和6年雇用動向調査」における「医療,福祉」分野は、入職率18.3%・離職率16.9%といずれも全産業(入職率15.0%前後・離職率14.2%)を上回ります。人材の流動が大きい分野であることは、公的統計からも確認できます。

看護職は資格職であり、有資格者が働ける場が病院以外にも広がっています。「動いた先がある」ことが数字に反映されている面は、考慮に入れておくとよいでしょう。

調査で挙げられている離職理由を6つに整理する

ここからは、各種調査で挙げられている離職理由を分類して見ていきます。なお以下はその理由を挙げる回答が一定数あったという話であり、看護職に就くすべての人に当てはまるものではありません。

1. 心身の健康問題——特にメンタル面

日本看護協会「2025年 病院看護実態調査」では、新卒採用者が年度内に離職した病院の看護管理者に対し、その理由を複数回答で尋ねています。回答した病院のうち、「健康上の理由(精神的疾患)」を挙げた病院が54.6%と最多でした(2024年度)。前年度は52.5%です。

ここで押さえておきたいのは、これは離職した看護師本人の回答ではなく、病院側(看護管理者)の認識であり、かつ分母は「新卒離職者が発生した病院」だという点です。「新人離職者の54.6%が精神疾患だった」という意味ではありません。

また同調査では、2024年度に病気で1カ月以上の連続休暇を取得した正規雇用看護職員がいた病院は72.6%、そのうちメンタルヘルス不調による休養者がいた病院は79.5%(平均5.4人)と報告されています。長期休養者が出た病院の多くで、メンタル不調が関わっている構図です。

これらの数値については、個人の資質の問題ではなく、勤務体制や人員配置といった構造的な要因を指摘する声が、看護関連の調査報告や労働団体の提言の中で繰り返し示されています。

2. 交代制勤務と夜勤の負担

日本医療労働組合連合会(医労連)「2025年 夜勤実態調査」では、次のような状況が報告されています。

  • 2交替制を採る病棟の割合が54.8%と半数を超え、増加傾向が続いている
  • 2交替職場のうち、16時間以上の長時間夜勤が病棟の47.5%、看護職員の46.0%
  • 3交替職場でも約4分の1が月9日以上の夜勤に従事

3交替から2交替への移行は、出勤回数が減るという利点がある一方、1回あたりの勤務が長時間化します。夜勤は生活リズム(概日リズム)の乱れを伴うため、疲労が回復しにくいことが一般に知られています。「このペースを40代・50代まで続けられるか」という問いが、働き方を考え直すきっかけになるケースは少なくありません。

用語メモ:2交替と3交替

3交替は日勤・準夜勤・深夜勤に分ける方式(1回8時間前後)。2交替は日勤と夜勤の2つに分ける方式で、夜勤1回が16時間前後になることが多い形態です。

3. 責任の重さと、能力・適性への不安

同じく新卒離職者が発生した病院の看護管理者への調査(複数回答)では、「自分の看護職員としての適性への不安」を挙げた病院が46.6%、「自分の看護実践能力への不安」が44.2%と上位に並びます(2024年度)。こちらも病院側の認識にもとづく数値です。

看護は、判断や処置が患者の安全に直結する仕事です。加えて近年は、医師の働き方改革に伴うタスク・シフト/シェアによって、看護職が担う業務範囲が広がっている領域もあります。責任の重さが、やりがいと負荷の両面に効いてくる構造だといえます。

用語メモ:プリセプター制度/クリニカルラダー

プリセプターは新人看護師に付く指導役の先輩。クリニカルラダーは看護実践能力を段階的に定義した育成の枠組みです。運用の実態は施設によって差があり、新人期の負担感を左右する要因になります。

4. 人間関係

同調査で「上司・同僚との人間関係」を挙げた病院は27.0%(2024年度、複数回答)。健康上の理由や能力への不安より順位は下ですが、4分の1以上の病院が挙げている項目です。

看護はチームで動き、申し送りや相談の頻度が高い仕事のため、人間関係が業務そのものに直結しやすい側面があります。一方で、これは施設や部署が変われば状況が変わりうる要因でもあります。「看護という仕事が合わない」のか「今の部署の環境が合わない」のかは、区別して考える価値があります。

5. ライフイベントとの両立

結婚・出産・育児・介護といったライフイベントも、長く指摘されてきた離職要因です。厚生労働省の看護職員に関する実態調査でも、「出産・育児」「結婚」は退職理由の上位に挙げられてきました。

夜勤や不規則なシフトは、保育園の預かり時間や家族の生活リズムと衝突しやすい働き方です。近年は夜勤免除や短時間正職員制度を設ける病院も増えています。制度がどの程度整備され、どの程度利用されているかは施設ごとに差があるため、就業規則上の制度の有無だけでなく、実際の利用実績(育児休業取得率、短時間勤務利用者数など)を確認するのが現実的です。

6. 給与・処遇への納得感

給与水準そのものは、他職種と比べて特別に低いわけではありません。日本看護協会「2025年 病院看護実態調査」によると、新卒看護師(高卒+3年課程卒)の初任給は基本給平均21万6,416円、税込給与総額平均28万5,078円で、前年調査から上昇しています。

ただし処遇が離職理由として語られる場合、問題になるのは絶対額よりも「納得感」であることが少なくありません。夜勤手当を含めて成立している総額であること、夜勤ができなくなると収入が下がること、責任の重さと見合っているか——こうした比較の中で不満が生じやすい構造があります。

「看護師を辞める」と「今の病院を辞める」は違う

ここが、この記事でいちばんお伝えしたい論点です。

離職率11.0%という数字は、その病院を離れた人の割合です。辞めた人が全員、看護の仕事から離れたわけではありません。医療・福祉分野で入職率・離職率がともに高い水準にあることからも、資格を持ったまま職場を移る動きが活発であることがうかがえます。

看護資格を活かせる場は、病院の病棟以外にも広がっています。

  • 外来・クリニック:夜勤がない、または少ない
  • 訪問看護:1対1の関わり。オンコール対応の有無は事業所により差がある
  • 介護施設・特別養護老人ホーム:生活支援の比重が高い
  • 健診センター・企業の健康管理室(産業看護職):日勤中心
  • 保育園・学校・コールセンター・治験関連(CRC/CRA):直接的な医療行為が少ない領域
  • 院内の異動:急性期から回復期・地域包括ケア病棟など、テンポの異なる部署へ

「夜勤がつらい」のか「急性期のスピードがつらい」のか「特定の環境が合わない」のか。何がつらいのかを特定すると、必要な移動の距離が変わります。院内の部署異動で解決することもあれば、施設種別を変える必要があることもあります。

用語メモ:急性期/回復期/慢性期

急性期は発症直後の集中的な治療段階、回復期はリハビリを中心に在宅復帰を目指す段階、慢性期は長期的な療養段階。同じ「病院看護師」でも、求められるスピード感・スキル・夜勤の負荷は大きく異なります。

続けるか、動くか——判断のための5つの問い

すぐに結論を出す必要はありません。モヤモヤを言語化するための問いを挙げておきます。

  • つらさの原因は、部署固有か・施設固有か・職種固有か? 異動で解決しうるなら、転職より先に検討する余地があります。
  • その状態はどのくらい続いているか? 一時的な繁忙期なのか、慢性的な人員構成によるものなのか。
  • 心身のサインは出ていないか? 睡眠障害、食欲低下、出勤前の動悸などが続く場合は、キャリアの判断より先に産業医・主治医への相談が優先です。長期休養に至る前に休む選択は、その後の選択肢を守ります。
  • 今の職場で得られているものは何か? 教育体制、経験できる症例、通勤、人間関係、収入。失うものも棚卸ししておくと、後悔の少ない判断になります。
  • 3年後、5年後もこの働き方を続けられそうか? 体力や家庭の状況の変化を織り込んだときに現実的かどうか。

なお、既卒採用者の離職率が16.1%と相対的に高いことについて、その理由を示す統計はありません。ただ、中途入職者が再び職場を移るケースが一定数あるという事実からは、一因として、移る前に職場の情報をどれだけ把握できるかが重要になると考えることはできます。

情報を集める手段を知っておく

「今すぐ辞める」のでなくても、選択肢を把握しておくこと自体が判断の質を上げます。看護職の場合、情報を集める手段は比較的整っています。それぞれ運営の仕組みが違うため、特徴を踏まえて使い分けるとよいでしょう。

  • 看護職特化型の転職エージェント(民間・成功報酬型):医療機関から紹介手数料を受け取る仕組み。看護職の求人に絞って扱うため、夜勤体制や勤務条件など個別の情報を持っていることがある。
  • 総合型の転職エージェント・転職サイト(民間):医療以外(治験関連、医療機器メーカー、産業保健、医療系IT等)への展開を考える場合の選択肢。
  • ナースセンター(都道府県看護協会が運営する無料職業紹介事業):公的な仕組みで、求職者・施設双方から手数料を取らない。復職支援研修などの情報も得やすい。
  • ハローワーク(公的):地域密着の求人、特に地方や小規模施設の求人が見つかることがある。

いずれも、登録=転職ではありません。求人票を眺めて相場観を持つ、条件を言語化する、といった使い方もできます。民間サービスと公的機関を併用して情報を突き合わせると、得られる情報の偏りを減らせます。

実際に求人を検討する際は、以下を確認材料にすると比較しやすくなります。

  • 夜勤回数・夜勤体制(2交替か3交替か、夜勤1回の時間)
  • 有給取得率、時間外労働時間、離職率などの数値を提示してもらえるか
  • 見学や面談で、実際に配属予定の部署のスタッフと話せるか
  • 応募・入職の判断を、自分のペースで決められるか

まとめ

  • 病院の正規雇用看護職員の離職率は2024年度で11.0%(日本看護協会調査)。直近は微減傾向です。
  • 他産業の離職率とは調査の定義・母集団が異なり、単純比較はできません。参考値として、厚生労働省「令和6年雇用動向調査」では全産業14.2%、「医療,福祉」16.9%(入職率18.3%)と、業界全体では人の出入りが活発です。
  • 設置主体・病床規模・地域によって数値には差がありますが、離職率の高低は職場の質を直接示すものではなく、転職機会の多さや採用形態など複数の要因が影響します。
  • 調査で挙げられている離職理由には、メンタル面を含む健康上の理由、夜勤・交代制勤務の負担、能力や適性への不安、人間関係、ライフイベントとの両立、処遇への納得感などがあります(新卒離職に関する数値は、離職者が出た病院の看護管理者による複数回答)。
  • 離職は「看護をやめる」ことと同義ではありません。資格を活かせる職場は病棟以外にも広く、院内の部署異動で解決するケースもあります。

この記事の位置づけ:ここで紹介した離職理由は、各種調査で挙げられた項目を整理したものであり、看護職に就くすべての人に当てはまるものではありません。同じ職場・同じ勤務条件でも、感じ方や向き不向きは人によって大きく異なります。実際に長く働き続け、この仕事に手応えを感じている方も数多くいらっしゃいます。
